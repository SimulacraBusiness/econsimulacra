Changelog
=========

All notable changes to EconSimulacra are documented here.

Next release
------------

- Added optional rule-based household SNS behavior with follow and unfollow
  rules, Hawkes-process tweet timing, memory-derived tweet intents, and
  SmolLM2-based English text realization.
- Added a parameter-limited local plain-text Transformers service for Tiny LM
  generation.
- Added time-dependent ``DynamicSupply`` and scheduled grid ``KeepOut`` events.
- Added optional candidate-file tweet replacement for rule-based households.
- Added behavioral-coherence intervention configurations for retail prices,
  supply, spatial access, mobility products, and social information.
